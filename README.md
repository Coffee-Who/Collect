# 收藏(第一階段網頁版)

把 IG、Threads、FB 看到的店、景點、食譜存成自己的資料庫。資料只存在使用者自己的手機(瀏覽器的 IndexedDB),沒有伺服器、沒有帳號。

## 檔案

| 檔案 | 用途 |
| --- | --- |
| `index.html` | 入口 |
| `style.css` | 樣式(深色照片瀑布流) |
| `app.js` | 全部功能 |
| `manifest.webmanifest` | 加到主畫面的設定,含 Android 分享目標 |
| `sw.js` | 離線快取 |
| `icons/` | App 圖示 |

## 放上 GitHub Pages

1. 在 GitHub 新增一個 repo,例如 `clipbox`。
2. 把這個資料夾裡的所有檔案上傳到 repo 根目錄。
3. repo 的 Settings → Pages → Source 選 `main` 分支、`/ (root)`,儲存。
4. 一兩分鐘後網址會是 `https://coffee-who.github.io/Collect/`。

## 裝到 iPhone

1. 用 Safari 打開上面的網址。
2. 按分享 → 「加入主畫面」。
3. 之後從主畫面的「收藏」圖示打開。

## 從 IG 分享進來

**Android(Chrome)**:加到主畫面後,在 IG 按分享,選「收藏」即可。

**iPhone(用捷徑)**:iOS 不讓網頁出現在分享選單,用「捷徑」App 代替:

1. 打開「捷徑」→ 新增捷徑。
2. 加入動作「URL」,內容填:`https://coffee-who.github.io/Collect/?url=`,後面接上變數「捷徑輸入」。
3. 再加入動作「打開 URL」。
4. 捷徑設定裡開啟「在分享表單中顯示」,輸入類型選「URL」和「文字」。
5. 命名為「存到收藏」。之後在 IG 按分享 → 「分享到…」→「存到收藏」。

捷徑會用 Safari 打開網址;若想在主畫面的 App 裡打開,改用「複製連結 → 打開 App → 按『貼上』」。

## 功能

- 首頁:照片瀑布流,點照片直接開原貼文,點「⋯」看重點、導航、改狀態、編輯、刪除。
- 存一筆:貼連結(會自動去掉追蹤參數,避免重複存)、貼說明、上傳截圖。
- 截圖文字辨識:在手機上用 Tesseract.js 辨識繁中與英文。第一次使用要下載約 20MB 語言檔,之後會快很多。
- 自動分類:依各分類的關鍵字判斷,抓店名、地址、類型,使用者確認或改分類後才存。
- 設定:編輯分類、欄位、判斷關鍵字;匯出 / 匯入備份(JSON)。

## 限制(第一階段)

- 網頁讀不到 IG 內容(瀏覽器的跨網站限制),要貼說明或上傳截圖。第二階段做成 App 後解決。
- iOS 可能清除網頁資料(換手機、清除 Safari 資料、長時間沒開)。請定期「匯出備份」。
- 圖片存在手機裡,每張約縮到 1000px 寬,大約 100–200KB。

## 本機測試

```
cd clipbox
python3 -m http.server 8000
```

打開 `http://localhost:8000`。離線快取只在 https 下啟用。
